# Analisis Karakteristik Platform

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Arsitektur** | Client-Server (Front-End & Back-End) | Standalone / Client-Server | Client-Server / Standalone |
| **Bahasa Utama** | HTML, CSS, JavaScript | Java, C#, C++, Python | Kotlin, Swift, Dart (Flutter) |
| **Distribusi** | Hosting Web / URL via Browser | Installer (.exe, .msi, .dmg) | App Store / Google Play Store (APK/AAB) |
| **Keunggulan** | Akses cepat tanpa instalasi, lintas platform | Performa tinggi, akses penuh ke hardware, bisa offline | Portabel, akses sensor/GPS, push notification |
| **Keterbatasan** | Akses hardware terbatas, ketergantungan koneksi internet | Membutuhkan instalasi & resource hardware tinggi | Ukuran layar terbatas, manajemen daya/baterai |
| **Contoh Aplikasi** | Tokopedia, Gmail, Web WhatsApp | VS Code, Photoshop, Spotify Desktop | WhatsApp, Gojek, Instagram Mobile |
