# Refleksi

Platform yang paling menarik untuk saya pelajari adalah platform mobile karena aplikasi mobile sangat dekat dengan kehidupan sehari-hari. Aplikasi ini dapat memanfaatkan berbagai fitur perangkat seperti kamera, GPS, sensor, dan notifikasi. Saya ingin memahami cara membuat aplikasi yang mudah digunakan serta dapat berjalan dengan baik pada berbagai perangkat.

Tantangan terbesar saat melakukan setup environment adalah memastikan semua tools terinstal dengan benar dan dapat digunakan melalui terminal. Terkadang perintah Git, Node.js, NPM, atau Java tidak dikenali karena instalasi belum selesai atau konfigurasi PATH belum tepat. Selain itu, Android Studio membutuhkan ruang penyimpanan yang cukup besar dan koneksi internet untuk mengunduh komponen tambahan.

Untuk mengatasi tantangan tersebut, saya akan mengikuti panduan instalasi resmi setiap tools dan memeriksa versinya melalui terminal. Jika terjadi kesalahan, saya akan membaca pesan error dengan teliti, mencari penyebabnya, dan memperbaiki konfigurasi yang diperlukan. Saya juga akan mempelajari penggunaan Git dan GitHub agar dapat menyimpan serta mengelola kode program dengan baik. Dengan langkah tersebut, saya berharap dapat menyiapkan lingkungan pengembangan yang sesuai dan lebih mudah memahami pemrograman berbasis platform.
